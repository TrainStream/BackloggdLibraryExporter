# Game Library Exporter
Warning! AI Slop user script! But it works!<br>
Newest version can be found here: <a href="https://github.com/TrainStream/GameLibraryExporter/releases">Releases</a><br>
The html export is the highlight feature, providing various filtering options.<br>
<br>
Works on the user pages of:<br>
[Backloggd](https://backloggd.com/), [GameFAQs](https://gamefaqs.gamespot.com/), [HowLongToBeat](https://howlongtobeat.com/),<br>
[IGDB](https://www.igdb.com/), [MobyGames](https://www.mobygames.com/) and [VNDB](https://vndb.org/).<br>
<br>
You need Violentmonkey, Tampermonkey, Greasemonkey or another user script manager to install and run this script on your browser!<br>
This browser userscript can be used when you enter your user page on the websites.<br>
It can export csv, json and html files.<br>
The more tags you choose for exporting, the longer is gonna take.<br>
> [!WARNING]
> If you are being rate-limited by a website, increase the Page Request Rate in the ⚙️ menu.<br>
> For example: 500–1000 ms, 1 page per request will most likely be safe, but much slower. <br>

# List of Features:
- Supports: Backloggd, GameFAQs, HLTB, IGDB, MobyGames and VNDB
- Export the user’s main video game library, or custom lists
- Download your library as `HTML`, `CSV`, and/or `JSON`.
- Includes core game data: title, game id, game url, status, release date,
- average rating, your rating, languages, length and cover image URL. (website dependable)
- Optional genre/platform/advanced scanning.
- Optional offline cover image support.
- Game statuses (Compelted, Playing, ec) and their sources can be configured manually.
- Configurable page requests per second. 
- Generates a polished offline HTML library viewer, not just a raw data file.
- HTML viewer includes searching, sorting, status filters, genre filters, platform filters, and release-date filtering.
- Interactive counters show how many games match each status, genre, platform, and filter combination.
- Column picker lets users show or hide covers, links, genres, emoji, platforms, status, languages, length, ratings, and release dates.
